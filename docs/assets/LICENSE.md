# Original Sandbox Artwork

The crossing map and three unit illustrations in this directory were created
for JEV Squad Lab. They contain no extracted Warcraft artwork or game files.

These four SVG assets are released under the Creative Commons CC0 1.0 Universal
dedication: https://creativecommons.org/publicdomain/zero/1.0/

Lucide interface icons are provided by the separately installed lucide package
under its ISC license. Phaser and Matter.js use their respective MIT licenses.
Warcraft III photographs supplied by Dave are not part of this asset license.
